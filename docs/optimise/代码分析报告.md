#### 1.1.1 Heatmap 组件（`/workspace/src/components/Heatmap/Heatmap.tsx`

**问题 1：Resize 处理中的事件监听清理风险**
```typescript
// 第 182-225 行: handleResizeStart 函数
```
- **风险点**：在组件卸载时，没有清理 mousemove 和 mouseup 监听器没有统一的清理机制。如果组件在调整大小过程中被卸载，监听器会造成内存泄漏。
- **建议**：使用 useRef 存储监听器引用，并在 useEffect cleanup 中统一清理
```typescript
const resizeMoveListenerRef = useRef<{ move: ((e: MouseEvent) => void, end: () => void} | null>(null);

// 在 handleResizeStart 中：
resizeMoveListenerRef.current = { move: handleResizeMove, end: handleResizeEnd };

// 添加专门的 cleanup useEffect:
useEffect(() => {
  return () => {
    if (resizeMoveListenerRef.current) {
      getDocument().removeEventListener('mousemove', resizeMoveListenerRef.current.move);
      getDocument().removeEventListener('mouseup', resizeMoveListenerRef.current.end);
    }
  };
}, []);
```

**问题 2：重复计算**
- **风险点**：dynamicStyle 计算在每次渲染时都在重新计算复杂的布局逻辑，虽然使用了 useMemo，但某些部分可以进一步优化。

#### 1.3.1 统一的事件监听器管理
```typescript
// 创建一个 useEventListener hook
function useEventListener(
  elementRef: React.RefObject<HTMLElement>,
  eventName: string,
  handler: (event: any) => void,
  options?: boolean | AddEventListenerOptions
) {
  const savedHandler = useRef<(event: any) => void>();
  useEffect(() => {
    savedHandler.current = handler;
  }, [handler]);
  useEffect(() => {
    const element = elementRef.current;
    const eventListener = (event: any) => savedHandler.current?.(event);
    if (element?.addEventListener(eventName, eventListener, options);
    return () => {
      element?.removeEventListener(eventName, eventListener, options);
    };
  }, [elementRef, eventName, options]);
}
```

#### 1.3.2 统一的 setTimeout/setInterval 管理
```typescript
// useTimeout hook
function useTimeout(callback: () => void, delay: number | null) {
  const callbackRef = useRef(callback);
  const timeoutRef = useRef<NodeJS.Timeout>();
  useEffect(() => {
    callbackRef.current = callback;
  }, [callback]);
  useEffect(() => {
    if (delay !== null) {
      timeoutRef.current = setTimeout(() => callbackRef.current(), delay);
      return () => clearTimeout(timeoutRef.current);
    }
  }, [delay]);
}
```

1. **useResizeObserver hook**
   - **来源**：Heatmap 中的 ResizeObserver 使用
   - **建议**：
```typescript
function useResizeObserver(
  ref: React.RefObject<Element>,
  callback: (entry: ResizeObserverEntry) => void
) {
  useEffect(() => {
    const observer = new ResizeObserver((entries) => {
      entries.forEach(entry => callback(entry));
    });
    if (ref.current) {
      observer.observe(ref.current);
    }
    return () => observer.disconnect();
  }, [ref, callback]);
}
```

2. **useLocalStorage / useSettings hook
   - **来源**：多处使用设置保存和加载

```typescript
function useEventBus<T>(
  eventName: string, handler: (data: T) => void) {
  useEffect(() => {
    eventBus.on(eventName, handler);
    return () => eventBus.off(eventName, handler);
  }, [eventName, handler]);
}
```

## 总结

1. **性能问题**：主要集中在事件监听器清理不完整和重复计算
2. **可复用组件**：多个 UI 组件可以抽象为公共组件

1. **高优先级**：修复事件监听器清理问题
2. **高优先级**：为核心模块（textReplace, rendererArgs 完善测试
3. **中优先级**：抽象公共组件和 hooks
4. **中优先级**：统一设计系统和样式抽象
5. **低优先级**：业务模块测试覆盖
