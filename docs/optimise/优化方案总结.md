# Logseq Text Toolkit 优化方案总结

## 概述
本文档记录了对 Logseq Text Toolkit 插件的全面分析和优化建议。

---

## 1. 功能完备性与性能分析

### 1.1 功能完备性
- ✅ **BlockView 视图系统**：支持列表、表格、画廊、看板、思维导图等多种视图
- ✅ **文本格式化工具栏**：支持粗体、斜体、删除线、代码、下标、上标、高亮、文本颜色、下划线、Cloze 等格式
- ✅ **多主题支持**：默认、Notion、Linear、深色、渐变、Tana、Indigo 等主题
- ✅ **宏渲染**：支持 `{{renderer :blockview}}` 宏
- ✅ **嵌套格式处理**：支持复杂的 Markdown 和 Hiccup 嵌套格式

### 1.2 发现的问题
1. **折叠/展开按钮被隐藏**：在 BlockView 的多种视图中，`.block-control` 被设置为 `display: none`，导致无法折叠/展开节点
2. **wrapWithQuotes 过度包裹**：很多场景下文本被不必要地包裹在引号中
3. **思维导图节点连接不自然**：bullet 点与父节点连接断开

---

## 2. BlockView 折叠/展开功能修复

### 问题描述
在 `mindMapView.css`、`galleryView.css` 和 `boardView.css` 文件中，存在以下代码：
```css
.ltt-*-root .block-control {
  display: none !important;
}
```

这导致了 Logseq 原生的折叠/展开按钮在这些视图中不可用。

### 修复方案
**已修复**：删除了这三个文件中的 `.block-control { display: none !important; }` 规则。

### 修改文件
- `/workspace/src/components/BlockView/mindMapView.css`
- `/workspace/src/components/BlockView/galleryView.css`
- `/workspace/src/components/BlockView/boardView.css`

## 3. wrapWithQuotes 场景分析

### 当前 needsQuotes 判断逻辑
```typescript
function needsQuotes(text: string): boolean {
  // 跳过已经是完整 hiccup 格式的文本
  if (text.startsWith('[:') && text.endsWith(']')) {
    return false;
  }

  return text.includes(' ') || text.includes('\u00A0') || 
         text.includes('\u3000') || text.includes('"') || 
         text.includes("'");
}
```

### 建议优化的场景
#### 3.1 不需要引号的场景（建议改进）
1. **普通文本**：如 "hello"、"你好" → 不需要引号
2. **连续的特殊符号**：如 "@#$%"、"🎉🎊" → 不需要引号
3. **中文标点文本**：如 "你好，世界！" → 不需要引号
4. **仅包含单种空格变体**：明确是单个全角空格或非断空格 → 不需要引号
5. **已有引号的文本**：如果文本自身已被引号包裹 → 不需要再次包裹

#### 3.2 建议保留的场景
1. **包含普通空格**：如 "hello world" → 需要引号
2. **复杂混合文本**：同时包含多种特殊字符和空格 → 需要引号
3. **Hiccup 属性文本**：当作为 Hiccup 标签的属性值时 → 可能需要引号

#### 3.3 优化建议
重构 `needsQuotes` 函数，使其更加智能：
- 只有当文本中包含普通空格（` `）时才强制需要引号
- 其他字符（如全角空格、非断空格、引号等）仅在特定情况下需要
- 添加更细粒度的判断逻辑

## 4. 思维导图 Bullet 连线优化方案

### 问题分析
当前的 mindMapView.css 中，节点之间的连线是通过伪元素 `::before` 和 `::after` 来绘制的，但是 bullet 点与父节点的连接不够自然。

### 参考项目
1. **logseq-plugin-bullet-threading**：使用 SVG 或 CSS 绘制连续的线条连接 bullet 点
2. **logseq-plugin-advanced-markdown-table**：提供了复杂 CSS 设计的思路

### 优化方案建议
#### 方案 1：使用 CSS 伪元素实现连续连线
```css
/* 示例代码思路 */
.ltt-mindmap-root .ls-block::before {
  content: '';
  position: absolute;
  left: -20px;
  top: 0;
  bottom: 0;
  width: 2px;
  background: var(--ltt-connector-color);
}

.ltt-mindmap-root .ls-block::after {
  content: '';
  position: absolute;
  left: -20px;
  top: 16px;
  width: 20px;
  height: 2px;
  background: var(--ltt-connector-color);
}
```

#### 方案 2：使用 SVG 连线
在每个节点中注入 SVG 元素来绘制更美观和灵活的连线。

#### 方案 3：改进现有连线样式
- 调整当前 CSS 中连线的起始和结束位置
- 优化 bullet 点的位置，使其与连线更好地对齐
- 增加连线的平滑过渡效果

### 推荐实现
推荐采用**方案 1 + 方案 3 的组合**，即：
1. 保留现有的 CSS 伪元素实现
2. 优化连线位置和样式，使其更自然
3. 确保 bullet 点与连线完美对齐
