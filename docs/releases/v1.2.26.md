# v1.2.26

## 重点：Logseq 内部 Live Dashboard

新增 `{{renderer :dashboard}}`，Dashboard 不再依赖每天生成静态 HTML。

- 实时读取当前 graph 的任务：Task 标签、状态、最近更新时间
- 统计最近 7 天 / 30 天任务
- 读取核心标签引用量
- 读取 `业务看板` / `金融报告` 页面中的内部 HTML asset 附件
- 点击附件直接使用插件内置 HTML Viewer 打开
- 页面内“刷新数据”按钮即时更新

## 页面结构

已在 DB 图创建：

```text
工作台
├── 工作台 Dashboard {{renderer :dashboard}}
├── 业务看板
└── 金融报告
```

业务 / 金融页面均包含：

```text
最新简报 / 最新报告
按周归档
按月归档
AI 写入规则
```

AI 只需把 HTML 作为 Logseq 内部 asset 附件挂到对应节点，不需要外部文件路径。

## HTML Viewer

保留 v1.2.25 的 HTML 阅读器能力：

- 内部 HTML asset 预览
- 右侧/左侧面板、宽度拖动、全屏
- 文字标注、quote + offset 还原
- 标注写回 HTML asset 子块
- Dashboard `block:<uuid>` 解析
- 脚本/远程资源默认关闭

## 使用

1. 安装 `1.2.26`，完全退出并重启 Logseq。
2. 打开页面 `工作台`。
3. 如宏不存在，在页面执行 `[Text Toolkit] Insert Dashboard`。
4. Settings → HTML Viewer → Dashboard asset 保持为空；不要填 `file:///` 或外部绝对路径。
5. 刷新页面即可读取最新任务、标签和内部附件。
